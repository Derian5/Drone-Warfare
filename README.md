# Drone Warfare

Пустой стартовый проект на **Godot 4**.

## Запуск

1. Установите Godot 4 (обычная версия, без .NET).
2. В менеджере проектов нажмите **Import** и выберите `project.godot`.
3. Откройте проект и нажмите **F6** для запуска основной сцены или **F5** для запуска проекта.

Основная сцена пока пустая: при запуске отображается тёмный фон.

## Структура

- `project.godot` — настройки проекта, окно 1280×720, рендерер Compatibility.
- `main.tscn` — пустая основная 2D-сцена.
- `icon.svg` — иконка проекта.
- `.gitignore` — исключения для кеша Godot и локальных сборок.
